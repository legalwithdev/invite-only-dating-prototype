# Name: not decided

"Cove" is a **working name only**. It is not cleared, and it is not free. This file records what was actually checked, so nobody re-litigates it from memory later.

## What the research found

**1. "Cove" was already a dating app.** Members-only, application-based dating app founded in 2018 by Charles Messow (Toronto); the name was derived from "COnversation + loVE". Verified members, limited invites per member to avoid unlimited swiping, and a 7–10 day text → voice → video progression. Public launch January 2019, official launch party in Phoenix in June 2019.
Sources: PR Newswire release (23 Oct 2018), AZ Big Media (19 Jun 2019), FOX 10 Phoenix (22 Jun 2019), Phoenix Magazine (17 Jul 2019).

Whether it is still operating could **not** be verified. Its site, meetinthecove.com, did not load when checked; the most recent independent coverage found is from 2019. A business database (Tracxn) still lists the company as an unfunded Toronto dating app, but that kind of profile is often auto-generated and was not treated as proof of life.

**2. "Cove" is a live product today, in an adjacent space.** joincove.app — "Cove: a private space for two" — is a private, end-to-end encrypted, one-time-invite-link chat for exactly two people, 18+, with a paid tier called Cove+. It is run from India and its policies were last updated 12 November 2026, so it is actively maintained. It is a messenger, not a matching app: no profiles, no feed, no discovery, no strangers.
Sources: joincove.app (homepage, privacy policy, terms, child-safety standards).

**3. The name is used by unrelated but funded brands.** Cove is a co-living operator across Indonesia, Singapore, Japan and South Korea with a live App Store / Play Store app (community-first app update, May 2026). Cove Family is a paid infertility support community.
Sources: Olenka (20 May 2026), covefamily.co.

**4. What was not found.** No currently listed "Cove" dating app turned up in app-store search results. That is an absence of evidence from a limited search, **not** evidence of absence, and it should not be written down as "the name is free".

## What this means

Three products, one of them a dating app and one an invite-only private chat, already sit on this name in spaces that overlap ours. Two consequences:

- **Trademark and app-store clearance is not optional** before any public launch. A name search in the relevant classes (9, 42, 45) plus app-store listings is the minimum, and that needs a lawyer, not a search engine.
- **Renaming is cheaper now than later.** The brand string lives in one file, `index.html`: the `<title>`, the gate heading and lede, the footer lines, the toast copy, the "Cove is locked" screen, and the profile footer. A find-and-replace plus one visual pass covers it.

## Shortlist space, if useful

Not recommendations — just the constraints the name has to satisfy: short, one word, no dating-app cliché ("spark", "kindle", "match", "vibe"), pronounceable in Indian English, and available as a `.app` or `.com` without a hyphen. Anything built on "invite", "circle", "vouch" or "table" is worth checking first, since that is the product's actual promise.

## Repo name

The repository is `invite-only-dating-prototype` deliberately — descriptive, brand-free, and safe to rename. GitHub redirects the old URL after a rename, so nothing breaks.
